# Ashima WebGL Noise

Textureless 3D simplex noise by Ian McEwan (Ashima Arts), maintained by Stefan Gustavson, MIT licensed (LICENSE preserved in `original/`). Upstream: https://github.com/ashima/webgl-noise (maintained fork: https://github.com/stegu/webgl-noise). Pinned to `6abed1e`.

Fills the gap left by the shared 2D value noise: smooth 3D noise for animated surfaces and volumes.
