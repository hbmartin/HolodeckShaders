# Holodeck Scene

https://github.com/chrislanejones/holodeck-scene: a single HTML file with hand-written WGSL, three.js geometry and Rapier physics. No license, so clean-room inspiration only. Originals are preserved only for permissive licenses. NC/SA or unlicensed sources are recorded here as metadata only (no files); see docs/shader-library.md.

Visual: black room with amber fine and coarse grid lines on every face, distance fade and slow pulse; metallic and glowing objects drifting in zero gravity; fixed camera.
