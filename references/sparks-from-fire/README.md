# Sparks From Fire

"Sparks from fire" by Jan Mróz (jaszunio15), https://www.shadertoy.com/view/wl2Gzc, licensed CC BY 3.0 (stated in the file header). Preserved here as adapted for Ghostty by Alex Sherwin (0xhckr/ghostty-shaders `85898f0`).

Generator: eight layers of rotating per-cell spark points with noise-warped UVs, layered value-noise smoke with holes and a vignette. The terminal texture is only sampled for the final blend, so the generator ports to a single pass directly.
