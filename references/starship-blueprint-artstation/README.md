# Starship Blueprint Shaders

ArtStation project XABr3 (https://dicewrenchdesigns.artstation.com/projects/XABr3) by Allen White, 2018; a talk is linked at https://www.youtube.com/watch?v=w2re4uv-z1U. Art reference only. Originals are preserved only for permissive licenses. NC/SA or unlicensed sources are recorded here as metadata only (no files); see docs/shader-library.md.

Content: vertex-colour channel packing (AO, impulse and warp glow, deflector colour), panel textures and normal maps, guide-light masks, and a "Blueprint Mode" render.
