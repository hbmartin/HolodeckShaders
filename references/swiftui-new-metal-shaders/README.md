# SwiftUI New Metal Shaders

MIT-licensed demos by Astemir Eleev (https://github.com/eleev/swiftui-new-metal-shaders, pinned to `6315085`). The repository's MIT grant cannot cover third-party code it ports without credit, so only the Apollonian gasket is preserved: it is a direct port of mrange's "Apollian with a twist" (Shadertoy Wl3fzM), whose header states CC0.

| File | Class | Provenance | Use here |
| --- | --- | --- | --- |
| ApollonianGasket | Generator | mrange Wl3fzM, CC0 | `apollonian-twist` |
| Fireworks | Generator | Uncredited GLSL (hash31 by Dave Hoskins) | Not adapted; `fireworks` uses BigWings' version |
| Lightspeed | Generator | Unidentified | Not adapted (overlaps `warp-speed`) |
| FractalPattern | Generator | kishimisu mtyGWy, likely CC BY-NC-SA 3.0 | Not adapted |
| BouncyHeart | Generator | Inigo Quilez heart (artwork, copyrighted) | Do not port |
| Psychodelics, Flame, GlowingWave, GradientWave, CirclePattern, CircleMesh, Mandelbrot, Noise | Generator | Unidentified; several have bugs (`bounds.wz` swap, NaN) | Not adapted |
| Kaleidoscope | Distortion | Generic | Covered by `polar-fold` |
| Wave, Pixellate, AngledStripes, StickySlide | Distortion/color | Generic | Not adapted |
