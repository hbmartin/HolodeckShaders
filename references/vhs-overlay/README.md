# VHS Overlay

Degraded VHS tape + CRT monitor effect for Ghostty by Alex Brinsmead (gist be7d2d2209d0dd3097000af369867927), MIT licensed with the full notice in the file. Preserved from 0xhckr/ghostty-shaders `85898f0`.

Post-process shader; the texture-free terms (grain, static, tracking band, vignette) can be multiplied or added over procedural colour.
